# Mentora Design System (Frontend Final)

## Brand
Calm, trustworthy, clinical but human. Dense professional workflow screens with low noise and explicit status communication.

## Tokens
- Primary Trust Blue: #2457D6
- Primary Hover: #1E47AF
- Background: #F6F8FC
- Surface Card: #FFFFFF
- Surface Subtle: #EEF2FA
- Text Primary: #111827
- Text Secondary: #4B5563
- Success: #1E8E3E
- Warning: #B76E00
- Danger: #B3261E
- Info: #3B82F6

## Typography
- Heading: Manrope (600, 700)
- Body/UI: IBM Plex Sans (400, 500, 600)

## Component Patterns
- Status chip: text + color, never color only.
- Conflict warning: icon + concise impact text + action hint.
- Dense cards for workflow data.
- Primary action buttons with clear focus ring.
- Location-enabled cards always show "Yol Tarifi Al".

## Product Rules
- Incoming request approval warns that overlapping available slots may auto-close.
- Appointment card supports CancelledByConflict visualization.
- Notification settings include SMTP test action.

## Accessibility
- WCAG AA contrast target.
- Keyboard navigable actions and forms.
- Focus visible on all controls.
